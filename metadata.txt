about=Tools for Romanian systematic cadastre work with CGXML files (ANCPI / OCPI, eTerra). The interface is in Romanian.

    * CGXML conversion: the .cgxml files of a folder, a ZIP archive or a file selection become an imobile (property) layer and a construcții (building) layer, as GeoPackage, Shapefile, DXF with labels or Excel, with the columns and field names you choose.
    * Intravilan / extravilan report: the area of every imobil inside and outside the intravilan, as a classified layer and an Excel report.
    * Area reduction: scales the deed areas of a parcel list so that they add up to a measured contour; parcels with a CF/IE (land book number or electronic identifier) keep theirs.
    * Comparator: two layers, or two sets of CGXML files paired by file name or by IE, with the imobile and construcții added, removed and changed.
    * Topology check: overlaps, gaps and unsnapped points between imobile, and construcții outside their imobil, returned as styled layers.
    * Building topology: cuts every construcție that crosses the boundary of its imobil back inside it.

    All results are in Stereo 70 (EPSG:3844); layers in other coordinate systems are reprojected. Every tool is also an algorithm in the Processing Toolbox. Layers and fields are preselected by name patterns set in the settings.

    The website cadex.ro, by the same author, validates, compares and queries CGXML files in the browser; the validator, the comparator and the predefined queries are free for one file at a time.

    Only DXF output needs an extra Python package, ezdxf, which the plugin installs into the QGIS user profile after asking.
